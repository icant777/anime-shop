# 动漫商城 · 云服务器部署手册（Docker 一条命令版）

这套东西已经全部配好，你不用改任何代码。全流程分三段：**买服务器 → 传文件 → 敲命令**。

---

## 第一段：买什么服务器

### 配置（照这个选，别买错）
- **2核4G 内存**（必须！2G 跑不动：JVM + MySQL + Redis + Nginx 会内存爆掉）
- 系统选 **Ubuntu 22.04 / 24.04**（Docker 支持最好）
- 地域随便（国内节点访问快，但要备案；香港/新加坡免备案但慢一点）
- 带宽 3M 起

买完记下三样：**公网 IP、SSH 端口(默认22)、root 密码**。

## 第二段：传文件到服务器

### 1. 把整个 `anime-deploy` 文件夹压缩成 zip
里面应该长这样：
```
anime-deploy/
├── docker-compose.yml      ← 总调度
├── backend/
│   ├── Dockerfile
│   └── app.jar             ← 已打好的后端（38M）
├── frontend/               ← 整个前端文件夹
├── mysql/
│   └── init.sql            ← 数据库初始化脚本
└── nginx/
    └── nginx.conf          ← 网页+反代配置
```

### 2. 传到服务器（在你自己的电脑上操作）
用 FinalShell 或 Xshell（图形化，不用记命令）连上服务器，把 zip 拖进去。

或者用命令行（Windows PowerShell）：
```powershell
scp anime-deploy.zip root@你的公网IP:/root/
```

### 3. 服务器上解压
SSH 连上服务器后执行：
```bash
cd /root
unzip anime-deploy.zip -d anime-deploy
cd anime-deploy
```
（若提示没有 unzip：`apt update && apt install -y unzip`）

## 第三段：装 Docker + 一键启动

### 1. 安装 Docker（Ubuntu，复制整段执行）
```bash
curl -fsSL https://get.docker.com | bash
```
国内若拉不动，换镜像源安装：
```bash
curl -fsSL https://get.docker.com | bash -s -- --mirror Aliyun
```

### 2. 启动全栈（核心的一条命令）
```bash
docker compose up -d
```
（旧版 Docker 用 `docker-compose up -d`）

这条命令会自动：拉镜像 → 建 MySQL 并导入 init.sql → 起 Redis → 起后端 → 起 Nginx。
**第一次要拉镜像，等 3~10 分钟**，之后秒起。

### 3. 看是否跑起来
```bash
docker compose ps
```
四个容器（mysql / redis / backend / nginx）状态都是 `Up` 就成功了。
看后端日志：`docker logs -f anime-backend`

### 4. 打开网站
浏览器访问：`http://你的公网IP`

- 首页、商品、登录注册、下单、领券、签到、发视频全部是**真实后端 + 真实数据库**
- 测试账号：`xiaoxu / 123456`
- （带横杠的库名 `xym-work` 已随 init.sql 自动建好）

## 三个坑（提前避雷）

1. **安全组/防火墙放行端口**：阿里云/腾讯云控制台的"安全组"要放行 **80**（网页）和 **22**（SSH）。不放行浏览器打不开。
2. **拉不到 JDK25 镜像**：若 `eclipse-temurin:25-jre` 拉失败，把 `backend/Dockerfile` 第一行改成 `eclipse-temurin:24-jre` 不行（class 是 JDK25 编译的，必须 25）。正确做法：换镜像源，或确认网络能访问 Docker Hub。
3. **数据库密码**：写在 docker-compose.yml 和后端环境变量里，别泄露。要改就两处一起改（yml 里的 MYSQL_ROOT_PASSWORD 和 MYSQL_PASS）。

## 复试怎么讲这个项目（加分点）

面试重点讲这 4 个技术点，都是真材实料：
1. **下单事务**：一个 `@Transactional` 包住扣库存+建订单+写流水+加积分，任何一步失败全回滚。
2. **防超卖**：用 `UPDATE ... WHERE stock >= 数量` 原子条件更新，不是先查后改。
3. **Redis 会话**：token 存 Redis 带 2 小时过期，退出即删。
4. **Docker 部署**：四容器编排 + Nginx 反代 + 健康检查，一条命令起全栈。

这套话说出来，比"我做了个商城页面"高一个档次。
